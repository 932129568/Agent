## 四、这一轮真正的技术判断（不是流水账）

1. **S3 是结构性缺陷，CSS 救不了**：每帧 `innerHTML` 重建整个 `mdBody`，用户的 `.think-body.open`
   必然丢失。修法是把思考区提升为兄弟节点，且**首建后只改 `textContent`**（连 innerHTML 都不用）。
   反向对照第一版把 `open` 写进了重建模板，是假对照——已修正并留档。

2. **A6 第一版是「有规则、无效果」的空机制**：钩子只罩 `[data-amb]`，而极光层早已
   `display:none`。运行时普查证明 idle 下真正在跑的 infinite 动画是 **0 条**，
   静态声明的 26 条是假象。改全元素作用域 + `!important`，并用注入元素证明 running→paused→running。

3. **契约判不出「还有没有人能到达它」**：删掉 Rail 的会话钮后，`#panelSessions` 不可达，
   但 id 与 4 个 `setSessionFilter` 字面量都在，两门全绿。补入口后会计回到 4→4。

4. **移植必须做差分验证**：py `round` 是十进制平局取偶（2.25→2.2），`Math.round` 是 half-up；
   `json.dumps` 默认分隔符带空格，直接影响字符数→token 预算判定。只读代码发现不了，
   真 Python 跑 17 组 fixture 逐项比对后才暴露。

5. **注释不是安全区（本轮三次）**：`contract_diff` 的 onclick 正则、A7 死控件扫描、
   A6 的循环计数正则，都会把注释里的连写示例当成真实内容。

6. **假精度常数**：`lightwell-skin-gate` 的 `scripts.length === 117`、`test_frontend_tree` 的
   模块顺序表、`test_r33_market` 的「功能市场」标签——都是断言钉在会变的事实上。
   改法是让断言守住**意图**，并确认覆盖在别处仍成立。

7. **V2 没有新增任何 js_api 方法**：L1 来自 body 的 system 消息，L2/L3/handoff 走
   `X-Harbor-Harness` 请求头（代理的 fwd 白名单只放 3 个头，自定义头天然不外泄）。
   这比新增方法少了一整圈契约改动（51/117/168 全程未变）。
