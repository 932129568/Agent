## 二、待落地清单（按建议顺序）

### P0-6 · 写前 Diff（server 侧，风险最低）

**位置**：`server/src/services/files.js` · `writeFile`（**L251**）、`searchReplace`（**L312**）
> 手册/补丁里的 L257、L807 等行号是 **r115 基线**的行号，与当前仓不一致；本文档一律用当前仓实测行号。

**现状**：`writeFile` 成功只返回 `{ok, path, bytes}`，没有前后内容；`searchReplace` 同样。

```js
// 现在（L258 附近）
return okJson({ ok: true, path: shortPath(target), bytes: ... })
```

**目标**：成功时附带
```js
diff: { before: prevText, after: String(content ?? '').slice(0, 20000) }
```
`searchReplace` 同形：`before: from.slice(0,16000), after: String(newText ?? '').slice(0,16000)`。
`before` 取写入前的文件内容（文件不存在则 `''`）。

**验收**：写一个已有文件 → 返回体含 `diff.before`＝原内容、`diff.after`＝新内容；新建文件 → `before===''`。

**风险**：返回体多一个字段。本仓有 25 个 server 门脚本对写类返回值做形状断言，**必须先跑 `python tools/run_normalized_gates.py`**；若 golden 对照逐字节比较，需要同步更新基线或把 `diff` 设为可选（只在调用方要时才带）。

**必须配套**：见 P0-4 的"剥离 r.diff"——`diff` 若留在工具结果里进模型上下文，会 **Token 膨胀**（每次写文件都把前后全文塞进对话）。所以下一项必须同批做。

### P0-4 · 工具缓存三处补齐 + 剥离 r.diff（与 P0-6 同批）

**位置**：`frontend/src/agent/run-controller.js` · 工具结果处理块（约 L1020–1040）

**现状（逐条核过）**：
1. `readFileSet` 失效已做（`invalidateReadCache`，r116），但**斜杠未归一**——`args.path` 用 `a\\b` 而缓存键是 `a/b` 时不命中；
2. `listDirsSet`（L422 声明、L981 写入）**从不清空**：写文件后列目录仍返回缓存，属缓存洞；
3. `run_command` 只清了 `readFileSet`，**没清 `listDirsSet`**；
4. `r.diff` 若由 P0-6 引入，**没有任何消费/剥离逻辑**（当前 grep 无 `.diff` 命中）。

**目标**：
- 写类工具成功后：`readFileSet` 精确删除（已有）+ **`listDirsSet.clear()`**；
- `run_command` 成功后：`readFileSet.clear()` + `listDirsSet.clear()`（现有已清前者）；
- 路径键统一：`String(p).replace(/\\/g,'/').toLowerCase()`；
- 解析工具结果后：若存在 `parsed.diff`，先 `dispatchEvent(new CustomEvent('harbor:diff',{detail:{sid,path,before,after}}))`（供 I23 副屏「改动」页用），**再 `delete parsed.diff`**，保证进入模型上下文的文本不含 diff。

**验收**：
- 写文件后立刻 `list_dir` → 必须看到新文件（不能是缓存）；
- 写文件后 `read_file` → 内容是最新的（现有用例已覆盖）；
- 一次 run 结束后检查 `session.messages` 里的工具结果 JSON **不含** `"diff"` 字段。

**风险**：改的是工具结果文本 → 会动 golden 与既有断言；`harbor:diff` 事件是新名字，不影响契约（CustomEvent 不计入 `dom_ids`）。

## 三、施工纪律（这份单子之外的坑，逐条都栽过）

1. **改完模板必须三步构建**：`html-to-jsx.mjs` → `react/build.mjs` → `frontend/build.js`。只跑最后一步时改动对用户不可见，而两道契约门全绿。
2. **推契约基线是三处同步**：`--snapshot` 生成文件 + `frozen-python-surface.json` 追加 `contract_baseline_r<N>` + `run_normalized_gates.py` 里的 `--compare` 指针。`tests/test_contract_diff.py` 按数值 max 自动发现锚点，推完要确认 pytest 真读到新锚点。
3. **新增顶层符号必须同步 `manifest.provides`**，否则 build 报"未声明=[…]"。
4. **不要新建 CSS 文件**（见 P3-1）。
5. **跨模块只能** `window['a'+'b']` / `uiSeamCall`；裸标识符会让 allowlist 从 164 涨上去。
6. 改服务端返回体的（P0-6/P0-4/P1-1），**先跑 `python tools/run_normalized_gates.py` 再动下一个**——这批是最容易把 25 个 server 门脚本一起弄红的。
