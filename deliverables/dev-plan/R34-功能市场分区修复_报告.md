# R34 · 功能市场「技能 / 连接器分区为空」修复

> 2026-11-05 ｜ 用户实测反馈：专家页正常，切到技能、连接器页显示「没有匹配的条目 / 共 0 项」

## 1. 现象与根因

截图里分类标签停在「技术工程」（蓝圈）。`hubRenderMarket()` 的分类标签是**写死的 15 个专家官方分类**，且 `hubSetMarketTab()` 切 tab 时**没有重置 `HUB_MARKET_STATE.cat`**。于是：

- 专家池 `section`：技术工程 / 产品设计 / 内容创作 …（15 类）
- 技能池 `section`：个人已装·热门 / 官方内置 / 连接器技能 / 插件技能 / 开发者插件市场 / 协作与团队市场（6 类，292 项）
- 连接器池 `section`：官方连接器（1 类，17 项）

切到技能/连接器后，旧的 `cat='技术工程'` 仍参与 `items.filter(it => it.section === s.cat)`，两个池里没有任何条目叫「技术工程」→ **恒 0 项**。旧搜索词同理会串台。

## 2. 修复（`frontend/src/shell/hub-market.js`）

| 改动 | 说明 |
|---|---|
| `hubMarketSections()` | 新增：按**当前池**收集 `section` 去重；专家/专家团按官方分类顺序排列，技能/连接器用真实分区名 |
| 分类标签渲染 | 从写死 15 类改为 `hubMarketSections()` 动态生成 |
| `hubSetMarketTab()` | 切 tab 时重置 `cat='全部'`、`q=''`，并清空搜索框 |
| `hubSetMarketSub()` | 专家 ↔ 专家团切换也重置分区 |
| 防御性回落 | 渲染时若当前池不含 `s.cat`，自动切回「全部」，不再出现空页 |
| 空态文案 | 改为「换个关键词或点『全部』分区试试」 |

`manifest.json` 登记新顶层符号 `hubMarketSections`（24 个 provides）；模块数 114 / 样式 14 不变。
