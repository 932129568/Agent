## 二、本轮修复（1 条）

### P8 · LAW-11 误判：新增的透明舞台窗被判成"亚克力冲突"

**现象**：`npm run verify` 第一步直接失败

```
[LAW-11] electron/main.js:1 -> Windows Electron 中 transparent:true 与
         backgroundMaterial 冲突会导致原生亚克力失效
```

**实情**（r30 新增）：

| 窗口 | transparent | backgroundMaterial | 是否冲突 |
|---|---|---|---|
| 主窗口 | ✗ | `'acrylic'` + `backgroundColor:'#00000000'` | 否 |
| `desktopStageWin`（全屏透明舞台，承载 3D） | ✓ | 无 | **否**（透明窗口本来就不该设材质） |

**根因**：判定写的是**整个文件级**"两串同时出现"，不是"同一窗口内混用"：

```js
if (/backgroundMaterial\s*:/.test(cleanMain) && /transparent\s*:\s*true/.test(cleanMain)) fail(...)
```

**改动**（`frontend/app/tools/enforce-iron-laws.mjs`）：切出每个 `new BrowserWindow({...})` 的花括号块，逐块检查是否同时含两者。

**反例验证（关键，否则等于把红的改成绿的）**

| 状态 | 结果 |
|---|---|
| 正常代码 | PASS |
| 临时给主窗加 `transparent: true` | **FAIL**（报"同一 BrowserWindow 内混用"） |
| 还原 | PASS |

正反两侧都对 ⇒ 新判定真的按窗口块生效，标准没有被放空。

> 与之前 `NOT_MIGRATED` 那条同源：**门禁用字符串匹配代替结构匹配**，一遇到"文件里有别的对象也用到同一关键词"就误伤。

## 三、遗留未修（4 条）

### 🟡 P7 · 助手「全自动监工」派发后拿不到验收单（连续 r29/r30 复现）

- **用例**：助手聊天输入「帮我做一份 MySQL 慢查询优化方案」→ 点「派发」→ 等
  `.cp-chat .cp-msg:has-text("全自动监工交付验收单")`，**12s 超时**。
- **已逐条排除**：
  1. 文案与分支存在 —— `CompanionOverlay.jsx:619`；
  2. 验收门槛不严 —— `companionAutopilot.js:333` `ok = score >= 60`，桩返回约 300 字（长度 +15、结构 +12）⇒ 评分 ≥70；
  3. 不是"质量不够"，而是**消息压根没产生**。
- **断点**（`CompanionOverlay.jsx:576-585`）：派发后置 `running: true`，然后等
  「出现新的 assistant 消息」或「`run.error`」—— **两者都没等到** ⇒ 该次 run 未正常产出。
- **最可能原因**：监工的模型调用没走当前会话端点（走了保存的模型配置），
  在 e2e 桩环境下拿不到回复，于是走 `else` 分支（助手说"没拿到完整正文"）。
- **未修原因**：修复需改助手派发链路，按你的要求**不动助手**。
- **建议交付方自查**：全自动监工是否复用当前会话的 `endpointConfig`；若它另读模型库配置，
  在"只有会话端点可用"的环境里就会沉默失败。

### 🟡 P3 · 助手浮层压住底部操作条（未改产品）

`.cp-actor { pointer-events: auto }` + 默认落点右下角（`x=vw-160, y=vh-168`），
层级 `--z-companion:175`；`.hb-main` 因 `will-change: transform` 形成层叠上下文，
**子元素抬 z-index 也压不过它**。受影响的按钮：群聊「发起接力」、工作流「中止执行」。

- 处置：产品未改（按要求）；e2e 侧开局隐藏助手，Suite T 前写回 `visible:true` 并重载。
- 建议改法：助手本体 `pointer-events: none`，改用文档级命中测试判断"点击是否落在助手身上"。

### 🟢 P5 · 「工具箱唤回助手」的承诺不存在

隐藏助手后的 toast 写「可在顶栏「工具箱」随时唤回」，但全仓只有这句 toast 提到"唤回"，
`visible: true` 仅由 `CompanionOverlay.jsx:81` 内部设置 ⇒ **界面内无法恢复**（只能改 localStorage）。

### 🟢 P6 · 设置保存的接口放大器（跨多轮遗留）

`settingsSlice.js` 每个保存函数末尾调 `refreshSettingsAux()`，
后者（`domainSlice.js:211`）一次并发拉 9 个配置接口 ⇒ 每保存一次 = 9 个请求。
建议 200ms 防抖合并（不改语义）。
