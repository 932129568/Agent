### 3.1 一处必须如实披露的证伪过程

首版实现把健壮性做成了 `calcUsage` **循环内逐字段 `num()` 箭头闭包校验**。隔离基准（2×2）证伪：

| 组合                         | 中位数                        |
| -------------------------- | -------------------------- |
| 旧 calc + concat（基线）        | 11.2ms                     |
| 旧 calc + **push**          | **5.2ms**（push 本身确实快 2.2×） |
| **新 calc（循环内校验）** + concat | 32.1ms（**慢 3×**）           |
| 新 calc + push              | 27.0ms（净退化）                |
| **出口兜底** + push（最终）        | **6.9ms**（净提升 1.7×）        |

即循环内校验在 vm 热路径未被内联，抵消并逆转了 push 收益。**未通过放宽判据掩盖**，而是把校验移到循环出口（6 次判定 vs 23 万次），既防住污染又保留性能收益。这是本轮最有价值的工程结论，已写入 `calcUsage` 注释。
